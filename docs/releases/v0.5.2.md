# arXiv Physics 0.5.2

- 将 DeepSeek 翻译提示词简化为两段自然指令，保留完整翻译、原文顺序、Markdown 与 LaTeX，不再要求长规则清单或特殊完成标记；续译指令也同步缩短。
- 打开或退出 DeepSeek 后，未复制译文的论文只显示“本地文件已下载”，不显示持续上传或翻译的进度条。手动复制超过 500 字符时仍自动保存并打开全屏本地预览。
- 新图标：深蓝背景、米白论文、青绿色轨道。使用生图设计稿复刻为 SVG，并生成 Android 矢量自适应图标，支持圆形图标和 Android 13 主题图标。
- 保留附件和提示词准备、手动发送、剪贴板保存，以及 0.5.1 的更新备用源和断点续传。

提示词不会改变 DeepSeek 本身的输出长度限制，长文仍可手动点击续译。应用不保证模型一次输出全部内容，也不会自动发送或复制网页回答。
