# arXiv Physics 0.5.1

- 检查更新改为并行获取 GitHub Release 与 jsDelivr CDN 的小型清单，每条请求总超时 8 秒，取消依赖 GitHub API。
- 设置中支持填写自己的国内 HTTPS 镜像清单地址；镜像同目录放置原版 APK，无需 GitHub 登录。
- 下载中断保留已下载部分，重试支持 HTTP Range 断点续传；镜像下载失败自动回退 GitHub，服务器不支持续传时重新下载。
- 校验文件大小、SHA-256、包名、版本以及与当前应用一致的签名，继续通过系统安装界面确认更新。

CDN 并非国内托管保证，实际可达性取决于运营商，清单缓存可能延迟。若需要稳定覆盖国内网络，应将清单和 APK 同步到自己可控的国内服务器或对象存储。未配置镜像时 APK 仍从 GitHub Release 下载。
